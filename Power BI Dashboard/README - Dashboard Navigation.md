# AdventureWorks BI Dashboard Navigation — README

## Dashboard Navigation Guide

The AdventureWorks BI solution consists of **three separate Power BI dashboards**, each focusing on a different business area. The dashboards are connected through navigation buttons using web URLs.

## How to Navigate

1. Open the **Executive Sales Dashboard**.
2. Use the navigation buttons at the bottom right to move between the three dashboards.
3. Select the desired dashboard:
   - **Promotions & Profitability**
   - **Customer Segmentation**
4. To return to the **Executive Sales Dashboard**, use the navigation buttons at the top left or top right of the page.

## Access Note

The dashboards are published separately and connected through web-based navigation. **Access to each dashboard depends on the sharing permissions configured for the Power BI reports.**
